# POC制作一回目

# 新規実装内容
基本機能 : :

全体：
・ログインの際に顔認証によるログインを行う

労働時間・打刻：
・権限ごとに打刻の編集や調整を行うことが出来るように。 

・打刻を入力できるのは、ログインしているユーザーしかログインできない

・打刻の作業は上司もしくは陸上から割り当てられた作業カテゴリを選択して打刻する(割り当てられた作業データなどと連携が行われるように。)

・作業項目をタップして作業開始を押下→作業記録が開始。開始した作業項目のボタンは色が変わり作業中になる。→作業が終了後、再度そのボタンを押して作業終了を押して終了してボタンは元の色に戻る。(基本的に並列で打刻を行うことが出来る)

労務管理記録簿　：

・一般的な船員と上司によって表示内容を分ける

・承認は上司しか行うことができないようにする

・表示されるのは基本的に他のユーザーのモノは表示されない。権限で与えられた人だけ他の表示や承認が出来るようになる。

航海日誌・点検 :

・航海日誌や点検などの項目は上司や陸上から追加することが出来る。記録内容も同様に。また数字についてはユーザーが入力できるように。

・記録入力できるのは、ログインしているユーザーしか出来ないようにする

当直・シフト管理 :

・当直の表示などは、ログインしているユーザーしか表示されない

・通常配置表は変更されたものをリアルタイムで反映されるようにしてください。船内の配置が表示される。

船内保守・作業記録：

・航海日誌・点検の点検内容と作業記録は被る内容があるため、海日誌・点検は日誌だけにして船内保守・作業記録に点検を統合するようにしてください。


デザイン(UI / UX) ::

全体：

・メニュー項目で注意通知の表示が出るとタイトルなどが崩れてしまうため、右側に通知表示を作成する。ニュースの速報なども表示できるように。


労働時間・打刻：

・労働時間で単純に打刻→打刻の中で履歴や後からの打刻が出来るようにする

・打刻の表示などは大きく、秒数まで表示する

・後から打刻の名称を変更する

労務管理記録簿　：

・労働時間や注意をもっと初心者が一目で分かりやすいようにする

・上司の承認表示や表示内容をもっと初心者が一目で分かりやすいようにする

航海日誌・点検 :

・出港、入港、出公前点検、安全パトロールのボタンの色が異なるため合わせる。

当直・シフト管理 :

・初心者でもすぐに分かりやすい表示にする
